I'm a project manager who got tired of only writing tickets, so now I build things too.

### What I'm building

Small apps that solve small annoyances, built with Claude as my coding partner:

- A coin collection app for iPhone. Everything stays on your phone, locked with Face ID or a PIN, with encrypted backups. There are no accounts and no servers.
- A roster app that turns a PDF roster into calendar entries, because PDFs are not a calendar.
- A browser extension that reads details from a page and turns them into a clean, ready-to-send message, so nobody has to copy and paste the same fields all day.
- An e-ink display for the kitchen counter that shows a roster at a glance, with a live progress bar while a rostered flight is in the air. A small Cloudflare Worker does the work, so the display only has to draw.

### How I work

I come up with the idea, decide how it should work and test the result. Claude does most of the typing.
